Privacy Policy

Last updated: November 19, 2026

The ThViceCity Clipper ("the app") is a personal tool operated by Sutavin (sutavin2004@gmail.com) to upload short videos to the ThViceCity YouTube channel. It is not offered to the public.

What the app accesses

The app uses the YouTube Data API with the youtube.upload permission, solely to upload videos to the operator's own channel. It does not read, collect, or store data about any other YouTube user.

Storage

The OAuth access token is stored only on the operator's own computer and is never shared or sold. No personal data is transferred to third parties.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Data retention and deletion

The app stores no YouTube user data other than the operator's own OAuth token, kept on the operator's computer. Deleting the local token.json file removes it immediately. To request deletion of any data, email sutavin2004@gmail.com; requests are completed within 7 days.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.
